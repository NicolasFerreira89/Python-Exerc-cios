# Python Exercícios 🐍

Este repositório contém uma coleção de scripts e exercícios práticos desenvolvidos em **Python**. O objetivo principal é consolidar os fundamentos da linguagem, praticar a lógica de programação e documentar a minha evolução nos estudos.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* Estruturas condicionais e de repetição
* Manipulação de strings, listas, tuplas e dicionários
* Tratamento de erros e modularização (funções/módulos)

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

* `PythonExercicios/`: Pasta principal que concentra todos os arquivos de código-fonte (`.py`) divididos por categorias ou desafios.

## 🛠️ Como Executar os Exercícios

Se você quiser testar os códigos localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Python-Exerc-cios
   ```

3. **Execute o arquivo desejado:**
   ```bash
   python nome_do_exercicio.py
   ```
